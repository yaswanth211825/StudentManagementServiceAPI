# Student Record Integrity QA Task Pack

This folder contains the inputs for a realistic manual QA task. It is designed for a tester to use the local Student Records browser page, not to inspect source code.

## Use these files in this order

1. Read `developer-task-brief.md` as the assignment from the developer.
2. Use `student-records.csv` as the source of synthetic test data.
3. Follow `expected-results.md` while testing in Safari.
4. Record observations in `issue-log-template.csv`.
5. Complete `qa-summary-template.md` after the test.

## Important

- The CSV is a reference sheet. Enter its values manually in the browser app; the current app does not include a CSV import feature.
- Use only these synthetic `.test` email addresses.
- Do not test against a database containing real student data.
- The final evidence package should be created only after the task idea is approved.
